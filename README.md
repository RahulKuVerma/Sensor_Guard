# SensorGuard

## Robust and Uncertainty-Calibrated Early Fault Prediction Under Progressive Multi-Sensor Degradation

SensorGuard is a research-oriented framework for evaluating early fault prediction under progressive multi-sensor degradation.

## Primary Dataset

NASA C-MAPSS Turbofan Engine Degradation Simulation Dataset.

## Main Objectives

1. Early fault prediction
2. Robustness under progressive sensor degradation
3. Predictive uncertainty estimation
4. Uncertainty calibration
5. Detection of unreliable predictions
6. Controlled analysis of machine degradation versus sensor-induced abnormalities
